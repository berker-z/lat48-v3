# LAT48 Site

Website for LAT48, a boutique team of operators who build, guide, and steady early ventures in crypto.

## Stack

- Vite + React + TypeScript
- Tailwind v4 (`styles.css` with `@theme` Nord tokens and typography utilities)

## Dev Notes

- Design tokens live in `styles.css`; see `design.md` (tokens/utilities) and `agents.md` (design directive) for guidance.
- Install and run: `npm install` then `npm run dev`
